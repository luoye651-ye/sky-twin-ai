# Agent指挥网页聊天

## 使用与启停

打开 http://127.0.0.1:5173/agent-command ，默认“自然语言助手”，原集群调度保留在“算法调度”页签。输入、消息/来源、状态composable及API模块分别维护，路由页只组合工作区。页签切换保留当前对话和已打开的调度页。

本机服务已部署于127.0.0.1:8002，原start.ps1默认会启动agent。单独启停：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\ruoyi\scripts\start.ps1 -Service agent
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\ruoyi\scripts\stop.ps1 -Service agent
```

只操作经PID/启动时间/路径核验的Agent进程树，不按Python名称批量结束进程，不停止Java或数据库。页面未就绪时，检查依赖/.env/本地模型和索引，点击“重新检测”。启动、健康检查与示例填入均不调用模型，点击发送才调用。

首次克隆代码仍需按README准备agent/.venv、依赖、本地模型和索引。FastAPI0.153.0、Uvicorn0.54.0仅安装在agent虚拟环境，旧backend/8000不参与聊天。

## 数据流与身份

Vue→Vite /agent-api→chat_service.py→Java /getInfo检查登录及sky:read→LangChain→MCP或本地RAG。

网页使用当前登录Cookie中的令牌作为Authorization头；Python把本次用户身份显式传给MCP，不回退到.env里的全局平台令牌，不把令牌作为问题或模型工具参数。API Key只留在服务端。所有网页问题都需要Java在线并通过鉴权，即使是纯知识问题；CLI纯知识模式仍可不依赖Java。仅允许本机5173页面来源，不开放跨域；部署公网前需重新设计HTTPS、反向代理、权限与费用策略。

Java继续唯一拥有任务/订单/事件状态，Python不新建业务数据库。聊天仅保留有限的在途请求、限流与响应重放缓存。

## 交互边界

- 展示真实工具处理进度和最终答复，不是逐token输出；来源可展开查看文件、章节、行号。
- Enter发送、Shift+Enter换行，输入法组词Enter不发送；示例按钮只填入文字。
- 支持停止等待、清空会话、服务重新检测；失败保留输入，不自动重试付费请求。
- 输出转义为纯文本，不执行模型或用户HTML；权限失败、断流等不显示为成功答案。
- 本页最近40条消息只在内存保存，刷新/离开或退出后不保存；每条问题独立查询，尚无多轮上下文记忆，请明确对象。
- 聊天不派机、不起飞、不结案；算法调度仍按原权限和人工确认流程执行。

## 费用与并发

每账号最多1个在途问题，全局最多2个，每账号每分钟最多6次新请求。成功响应按账号/request_id临时缓存10分钟（最多100条，不含凭证）；重复请求可重放结果，但仍重新鉴权，重启后缓存失效。前端不自动重试。停止等待会取消本地协程及清理子进程，但供应商已接受的请求可能仍计费；手动发送新问题也可能产生费用。
