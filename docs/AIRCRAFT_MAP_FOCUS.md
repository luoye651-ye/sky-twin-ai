# 飞行器资源点击定位

## 使用与规则

在数字孪生页面点击左侧任一飞行器卡片，地图会将对应模型居中，并高亮卡片和地图标签。卡片也支持 Tab 聚焦后按 Enter 或空格。

- 定位为一次性视角切换，不是自动跟随；再次点击会重新读取模型当前展示位置。
- 模型尚在加载时保留最后一次定位请求，加载完成后执行。点击预设视角会取消待执行的定位。
- 场景加载失败、模型没有可显示的位置时显示提示，不伪造场内位置。
- 使用渲染模型的世界坐标，保留已有展示抬升、飞行插值和明确标注的仿真布点规则；不是把业务坐标写回地图或数据库。
- 只调整相机，不改变飞机位置、任务指派、起飞状态或 Java 业务数据。

## 数据流与学习点

`FleetPanel` 发出飞机 ID → `DigitalTwinWorkspace` 记录本地选中 ID → `CityViewport.focusAircraft` 处理加载状态 → 场景按 ID 找到模型 → `aircraftFocus.ts` 调整相机与 OrbitControls 目标点。

选中样式通过 props 单向传递；相机操作通过组件公开方法调用。不要用点击卡片去改飞机坐标，也不要用每次快照刷新触发相机定位，否则用户拖动地图会被持续打断。
