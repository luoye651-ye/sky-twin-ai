# 环境发现 → 应急处置闭环第一版

## 本轮交付与真实边界

入口为大屏「环境发现」`http://127.0.0.1:5173/environment`；「应急处理」复用同一事件处置工作区；「巡检报告」可以查询、下载和追溯环境归档。

本轮聚焦**河道漂浮物**，实现：

> 巡检任务关联 → 图片上传及人工框选 → 人工确认/驳回 → 地理事件 → 应急侦察任务 → 服务端完成事件上空飞行 → 人工提交处置后图片与说明 → 事件解决及不可变报告。

当前没有配置或下载影像识别模型，没有调用外部AI服务。标注来源固定为`manual_annotation`，**不输出模型置信度**。图片来源（仿真示例/用户实拍资料）、WGS84位置和采集时间由用户声明；系统没有验证拍摄设备、自动地理定位或图片实际内容。关联巡检任务也不等于证明该图片由无人机拍摄。

应急任务是本地仿真的**空中侦察**，不是垃圾抓取、投送、真实救援或实机控制；清理结果由人工提供，报告不证明现实中已清理。卫星、北斗实机、视觉模型训练/推理均未新增。

## 用户操作

1. 在任务管理新建「环境监测」任务，分配空闲无人机并执行。影像可关联执行中或已完成巡检，不能关联未执行或其他类型任务。
2. 进入环境发现，选择巡检、填写标题/经纬度/带时区的采集时间，声明图片来源，上传PNG/JPEG。调整人工标注框（原图比例0～1），再提交。页面默认框只是表单初值，不是算法识别结果。
3. 检查原图、标注、SHA-256与坐标，填写复核原因并选择低/中/高等级。驳回不生成事件；确认生成一条原有`st_event`事件及关联信息。
4. 选择不同的出发站、回收站，创建应急侦察。航线为出发站起飞 → 80m巡航经过事件上空 → 到回收站降落；不创建河面起降站，也不在事件处降落。任务/航程仍受既有约束；事件过近导致重复航点、过远超过航程或穿禁飞区会拒绝整个创建操作。
5. 可以直接在详情分配、执行，也可进入Agent指挥页批量优化分配；冲突时进入多机协同预约错峰。应急任务不绕过电量、载重、终端定位互斥、空域或多机安全规则。
6. 若侦察取消或失败，可创建新的尝试，旧记录保留。一个事件同一时刻只允许一个未结束的侦察任务。
7. 最新侦察完成后，填写人工处置说明并上传不同于发现原图的处置后图片。服务端核对实际经过事件点的空中轨迹，原子保存后图、解决事件和冻结归档报告。
8. 在详情或巡检报告读取报告、下载TXT或查看证据快照。选择记录会写入页面查询参数，刷新或分享本机深链接可恢复同一记录。

地图只覆盖现有杭州主城区模型；模型外坐标不会伪造成场内点。标记依据用户声明位置，不提供自动地理定位。

## 状态与规则

| 发现状态 | 允许的操作 | 不允许的操作 |
|---|---|---|
| pending_review | 人工确认或驳回 | 创建侦察、结案 |
| rejected | 查看原始证据与审计 | 派任务、结案、反复复核 |
| confirmed | 创建应急侦察 | 无侦察直接结案 |
| in_response | 派机/执行、结束后重试，满足证据门槛后结案 | 并行重复创建未结束尝试，失败/取消当作完成 |
| closed | 只读证据、尝试、报告、下载 | 修改后图、重新派机、重复结案 |

发现状态是事件工作流，响应任务始终使用原`st_task`状态机，不维护另一套飞行进度。普通低电量/飞行失败告警仍走原通用处置流程；关联环境发现的事件，Java拒绝通过通用`/sky/events/{id}/resolve`绕过证据闭环。

确认等级给应急任务设置优化调度优先级下限：高3、中2、低1。服务端取调用者本批优先级与事件下限的较大值；页面也不允许下调。原算法依旧先最大化分配数，再最大化优先级，最后最小化成本；这不是正在执行任务的抢占，也不保证每个高等级事件都立即分到资源。

应急路线编辑必须保留距离事件点10m内的空中航点。结案还要求最新任务已完成、没有其他活动尝试，并确有`st_track`中距离事件点10m内且高度大于0的实际仿真轨迹。仅伪造完成字段、从地面经过或删除必经航点都不满足门槛。

## 影像与证据

- 接收PNG/JPEG，单图最多2MiB、宽高各不超过4096、总像素不超过1200万。Java先读取尺寸再实际解码，拒绝空文件、伪扩展名、SVG/GIF等格式。
- 原始字节与SHA-256保留在专用库；不使用用户文件名作为文件路径，不向公共静态目录写入影像。显示文件名取不含目录的末段。
- 图片接口需要`sky:read`，返回真实检测出的MIME、`nosniff`与`no-store`。浏览器携带令牌读取Blob，组件卸载/换图时释放Object URL。
- 标注框必须是有限数值且完整在图片内。API支持1～20框，第一版表单一次编辑1框。坐标是比例而非屏幕像素，缩放原图时保持比例。
- 采集时间使用带时区的Instant输入、按UTC存储和标注；允许过去365天至未来5分钟。审核/结案/审计时间来自Java服务器，沿用现有本地业务时间显示。
- 提交UUID和规范请求/原图哈希构成幂等约束；相同提交重试返回同一发现，相同UUID内容变化拒绝。页面在字段/文件改变时生成新UUID，不变内容的重试不重复创建。
- 处置后图必须与原图字节哈希不同，但**不同哈希不等于已证明真实处置**。无图像内容鉴伪、前后图自动比对或清理效果模型。
- 所有`sky:operate`调度员可以提交、复核和结案；未实现独立审核角色或强制双人复核。普通只读角色只能查看证据/报告。

## 架构与事务

新增幂等迁移`ruoyi/backend/sql/sky_twin_v8_environment.sql`接入`migrate-sky.ps1`：

- `st_env_discovery`：原图/后图字节、哈希、人工标注、任务关联、来源、复核与结案。
- `st_env_response`：不可变的应急侦察尝试、任务关联及优先级下限。
- `st_env_report`：结案时冻结的文本与JSON快照；与普通`st_report`飞行摘要分开，不覆盖原摘要。

不改写旧订单、站点、飞行器或历史轨迹；不向FastAPI复制状态。原`SkyService`、`RouteService`、`DispatchService`及多机安全服务继续负责创建、规划、分配和起飞。新页面和若依复用同一组Java接口及业务服务。

写操作先取得原多机时钟行锁，再锁发现与相应任务/资源，保持与既有调度一致的串行化顺序。并发确认只创建一个事件，并发响应只创建一个活动尝试，并发结案只生成一份报告。

图片、发现与上传审计同事务；复核、事件和审计同事务；任务、航线、尝试和响应审计同事务；后图、事件解决、结案审计和报告同事务。后续写入失败一并回滚，不保留半套业务。

沿用原空域服务的独立检查证据：拒绝或晚期创建失败可能留下带当时航线及标题的空域检查记录，即使对应临时任务回滚，这是有意保留的拒绝/检查证据，不是可执行的孤立任务。检查通过也不意味着外层业务最终提交成功。

报告冻结原始来源、标注、复核人、等级、所有尝试摘要、最新完成任务路线与完整轨迹、前后图哈希、处置说明与结案人/时间。报告内容为系统模板，不是大模型生成结论。原始证据、尝试和报告没有对外修改/删除接口。

## 页面职责

Vue路由保持薄组合。`EnvironmentWorkspace`选择记录、组合地图与功能；`DiscoveryForm`管理上传草稿；`DiscoveryReview`展示受权限保护的原图和复核输入；`EnvironmentalResponse`负责任务创建与动作；`EnvironmentalClosure`收集后图和结果；`EnvironmentalReport`读取/下载快照。`useEnvironment`负责请求、卸载失效保护、错误/成功区分与4秒只读轮询，飞行推进不由页面执行。

应急页面复用同一工作区，只隐藏发现提交表单；旧告警仍保留。巡检报告加入独立环境报告列表。Three.js复用CityViewport及已有点标记，没有加载第二套模型或渲染器。

## API

统一前缀`/sky/environment`。

| 方法 / 路径 | 权限 | 输入 / 返回 |
|---|---|---|
| GET `/discoveries?status=...` | sky:read | 最近200条摘要；不含图片字节 |
| GET `/discoveries/{id}` | sky:read | 来源/标注/复核/尝试/审计/报告引用 |
| POST `/discoveries` | sky:operate | multipart：`input`为application/json，`image`为图片 |
| GET `/discoveries/{id}/image?after=false` | sky:read | 原图，after=true为结案后图 |
| POST `/discoveries/{id}/review` | sky:operate | decision=confirm/reject、severity、reason |
| POST `/discoveries/{id}/responses` | sky:operate | startStationId、endStationId、reason |
| POST `/discoveries/{id}/close` | sky:operate | multipart：JSON input含resolution，image为后图 |
| GET `/reports` | sky:read | 最近200条环境报告摘要 |
| GET `/reports/{id}` | sky:read | 不可变文本与证据JSON快照 |

任务分配/执行/取消仍调用原`/sky/tasks/{id}/{action}`；航点、多机预约和批量派机接口不另行复制。
