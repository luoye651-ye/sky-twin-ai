# 杭州主城区数字孪生场景

数字孪生页使用约 72.1 × 77.9 公里的杭州主城区离线场景，WGS84 范围为 `[119.90,29.90,120.65,30.60]`。这是浏览器可交互的主城区矩形范围，不等同于杭州市完整行政辖区；矩形边缘会包含少量相邻地区。

## 数据和细节层级

- 数据源为项目已有的 OpenStreetMap France 浙江 PBF，许可 ODbL-1.0。
- `120.10～120.28,30.10～30.29` 的滨江及钱塘江两岸保留全细节。
- 主城区外围使用 LOD：保留主要道路、水体、绿地、显式高度/命名/大型建筑以及稳定抽样的代表性建筑。
- 当前离线 JSON 为 18.61 MiB，包含 36,057 个建筑、36,000 段道路和 9,000 个地表对象。资源由 `scripts/build_hangzhou_core_region.py` 从本地 PBF 重建。
- 场景按视距调整标签：全域总览优先展示 6 个站点，缩放到城区后再显示无人机信息卡。建筑/道路按 6 公里格网和材质批处理，装饰和车流继续使用固定上限。
- 业务高度低于 120 m 的场内飞行器会按稳定 ID 顺序在 220/260/300/340 m 的展示层中绘制，避免模型被大范围地图遮挡；该策略只影响 Three.js 坐标，不修改 Java/数据库高度。信息卡会同时标出展示高度与业务高度，达到 120 m 后直接按业务高度绘制。

## 六个仿真站点

旧种子数据的站点名称面向杭州业务，但坐标位于上海。迁移脚本 `ruoyi/backend/sql/sky_twin_v2_hangzhou_core.sql` 只匹配未修改的旧上海演示坐标，保留站点编号和订单/任务外键，并写入迁移审计。飞行器仅在空闲且仍位于旧演示坐标时随停放点迁移；历史轨迹不改写。

当前仿真坐标覆盖滨江、城西、主城、钱塘东部和萧山机场方向。这些是项目仿真站点，不代表已审批的真实起降设施或实机能力。

## 验证记录（2026-10-18）

- 高度策略加入纯函数测试后，城市场景测试为 15 项；四个 0 m 业务高度分别得到 220/260/300/340 m 展示层，150 m 业务高度保持 150 m。实际浏览器滨江城区视角显示 D-01 标签“展示高度 260 m · 业务 0 m”。
- 区域、坐标、几何、外观与 UAV 共 12 项测试通过；杭州场景模块独立 `vue-tsc` 类型检查和完整 `npm run build` 均通过。
- 实际 `CityViewport` 浏览器验收：`stationInstances=6`、六个站点标签、`outsideStations=0`、`outsideAircraft=0`、4 个 UAV 实例。
- 1920 × 1080、DPR 1、Chrome 无头浏览器全域视角：约 1,292 次绘制、3,422,850 个三角形、1,251 个几何、19 个纹理；最近帧间隔 P50/P95 约 6.3/19.7 ms。该数据包含无头浏览器和后处理开销，不是用户设备 GPU 帧率保证。
- 验收过程中曾短暂读到同期未接完的物流确认送达 props 类型错误；未修改该学习中的物流代码。用户后续保存完成后，最终完整构建退出 0。
