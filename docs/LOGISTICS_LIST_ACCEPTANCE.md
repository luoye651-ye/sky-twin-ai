## 本次可以重点读懂的一条记录

报告中的 `sampleOrder` 来自真实查询：

```json
{
  "status": "created",
  "taskStatus": "cancelled"
}
```

这是测试主动取消了它自己创建的任务后得到的结果：`status` 来自订单表，`taskStatus` 来自关联任务表。它证明JOIN读取了两个独立状态。订单取消业务尚未实现，所以本阶段任务取消并未同步改成订单取消；页面后续必须显示运输状态，不能把订单created一律误报成仍在运输。

`data: []` 表示查询成功但没有订单，并非接口失败；此前和本次测试业务数据都已清理。
