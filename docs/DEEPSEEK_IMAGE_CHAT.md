# DeepSeek 图片自然语言对话（2026-11-15）

入口：`/agent-command` → 自然语言助手 → 勾选“图片＋自然语言（现有DeepSeek）”。上传PNG/JPEG，输入“这张图有哪些疑似漂浮物”“重点看左下角”等问题，确认图片可发送至DeepSeek后点击发送。成功后可以不重新选图，继续追问；换图会清空该图片历史。

## 使用现有服务

只复用本项目现有的 `DEEPSEEK_API_KEY / DEEPSEEK_MODEL`，没有新增服务商、密钥或模型下载。[DeepSeek官方视觉文档](https://api-docs.deepseek.com/guides/vision/)确认 `deepseek-flash` 支持真实图片输入。本机配置检查仅输出支持能力/是否已配置布尔值，不披露配置内容。

支持名单为官方Flash及兼容旧别名；纯文字模型如 `deepseek-v4-pro` 明确显示不支持，不会悄悄切换模型或伪造看图成功。只发送用户上传的内联图片，不接收远程图片URL、不读取任意本地文件、不上传到Files API。

## 结果与边界

- 看图模式直接发送原图字节与问题至DeepSeek，返回概要、最多20项候选观察、相对位置、不确定性及复核提示；不是先读YOLO标签再假装看图。
- YOLO上传检测仍保留原有入口。YOLO输出检测框和模型置信度；DeepSeek回答开放问题与可观察细节，两者来源明确区分，不能把候选观察数量称为精确检测框数。
- 不根据照片推断真实坐标、拍摄时间、人员身份或处置完成，不自动创建事件、派机或起飞。需要入业务闭环时继续使用原人工证据/复核服务。
- 每张图片≤2MiB，格式按字节识别，最大边4096、总像素≤1200万。换图重置历史；保留最近3轮，20分钟无活动过期，重启后需要重新上传。
- 图片上下文按账号、令牌哈希、会话UUID隔离，最多20个缓存会话；原图不写入AI技术库/业务库，上传框架可能使用系统临时文件。工作台只保存问题、图片哈希、结果与模型用量，便于追踪。
- 每轮都需确认可把图片、问题及最近3轮问答发送至DeepSeek，会产生API费用。拒绝、截断、畸形结果或连接失败不展示为成功；不自动重试不确定请求。共享工作台每账号30次运行/24小时和60次模型调用尝试/24小时额度。

## 实现与验证

`AgentImageAttachment` 只处理附件、预览和授权；`useImageChat` 管图片上下文；原 `useAgentChat` 在文字/图片两条路径间选择；`AgentVisionResult` 显示结构化候选。文字聊天流协议不变。

`POST /vision-chat` 使用若依身份和sky:operate，校验图片后调用固定DeepSeek端点；`GET /vision-chat/health` 只检查本地配置，不调用模型；`DELETE /vision-chat/{conversationId}` 清除当前身份的图片缓存。独立合成演示没有挂载这些接口，不能绕过其禁止模型调用的限制。

模型输入和输出经过本地HTTP替身验收，覆盖原图Base64、真实解码、连续追问、账号/令牌隔离、过期、失败、不支持模型和输出截断。测试替身不算真实模型看图准确率。真实模型验收须另有实际请求记录，不能把文档能力或本地协议测试当作实测结果。

本轮110项Python隔离回归、72项前端检查及Vue类型检查/生产构建通过；其中看图专项10项，额外验证清空会话时在途请求返回不能重新写回图片缓存。Agent已加载，健康正常，未登录访问看图健康接口返回401。本地项目知识为4份30段，原20+8+5条检索回归通过。

用户明确授权“仅1次合成图请求”后，实际调用现有deepseek-flash：新生成384×256白底红方块/蓝圆形，无项目资料、业务记录或个人影像；返回正确的颜色、形状与左右位置，用量421输入/141输出Token。仅证明一次视觉接口/结构化输出可用，不作为漂浮物或真实现场检测准确率。记录：[真实合成图验证](verification/deepseek-image-chat-live.json)。没有重试或发起第二次真实请求。真实账号网页上传与真实业务影像效果尚未验收。
