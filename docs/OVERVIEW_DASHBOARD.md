# 运行总览可视化

运行总览 `/general` 采用三列布局：左侧三块机队/任务面板，中间复用杭州数字孪生场景，右侧三块任务/站点/告警面板。窄屏降为两列和单列，内容允许纵向滚动，不缩小整个页面来塞满屏幕。

## 六块数据面板

1. 机队运行状态：空闲、已分配、飞行中环形图，以及机型数量。
2. 机队电量监测：资源电量条及有效电量平均值；没有读数显示短横线，低于等于30%提示黄色。
3. 任务场景分布：物流、通勤、环境、救援、空域五类任务柱形图。
4. 任务生命周期：待分配、已分配、执行中、完成、取消、失败环形图。
5. 低空站点网络：五类站点条形图，单独显示启用/登记数量。
6. 告警与处置态势：未处置告警等级计数及最近三条未处置事件。

下方保留最新任务表和操作记录。各面板提供到对应业务页的详情链接。顶部四项指标仍使用Java `summary`，不是重新由前端截断列表估算。

## 数据流和口径

`Java snapshot/SSE → useSkyStore.snapshot → OverviewBoard → OverviewDashboard → buildOverviewMetrics → 图表组件`。

统计函数只读、无请求、无随机数、不修改快照。空数据显示0或空提示，断线时显式说明最后快照，不伪造趋势、完成率、成功率或同比。

Java当前返回全量未删除飞机/站点；任务、事件、审计最多最近500条。因此侧边任务分布、状态分布、告警等级只代表快照子集；顶部 `summary.completed/openEvents` 是服务端全量指标，两者不能互当分母。地图与资源为既有业务仿真，不是实机遥测。

## 组件划分

- `OverviewBoard` 只连接Pinia状态与展示容器。
- `OverviewDashboard` 负责布局、统计派生和组件组合。
- `OverviewPanel` 提供一致的发光边框、标题、入口与统计脚注。
- `OverviewRing`、`OverviewBars`、`OverviewBattery` 只接收数据并绘图。
- `OverviewRecords` 呈现任务表和审计列表。
- `CityViewport.overview` 仅调整总览中的标题/控制器样式，默认关闭，不改变其他页面布局。

未新增图表依赖，使用原生SVG与CSS；未改Java业务接口、数据库或权限。修正原地图空覆盖物的无参`Object3D.add()`错误，使用复制children列表的逐个转移，不跳过重挂载中的元素。
