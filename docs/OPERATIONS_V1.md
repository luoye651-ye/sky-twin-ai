# 业务运营增量（2026-11-08）

本轮按“直接实现、先完成代码与隔离验证”推进。Java 是任务和业务状态的唯一来源，Python Agent 只查询和起草文本，前端展示与提交明确的操作。入口：[业务运营中心](http://127.0.0.1:5173/operations)，另有原航线规划页的“生成绕行候选”按钮。

## 功能与验收规则

| 功能 | 已实现 | 服务端规则 |
| --- | --- | --- |
| 任务运营 | 全库分页、类型/状态/文字过滤、待处理提醒、失败/取消任务重试 | 创建关联的新任务，原任务和轨迹不改；同一原任务不能有多个活动重试；物流生成新订单并填写新期限；关联环境任务复用原处置服务；通勤使用班次入口 |
| 资源运维 | 充电、维修、故障登记，历史记录与恢复；站点容量配置 | 充电结束电量不能低于开始；维修/故障保持原电量；故障与关联任务失败在同一事务；运维中不能用于新任务；容量不能低于当前占用或已排未来班次峰值 |
| 检测历史 | 分页、状态筛选、预测详情、关联发现、失败分析重试 | 仅重试本人的失败记录，复用原图创建新分析；保留原失败证据，结果仍需原发现/人工复核流程 |
| AI 历史查询 | 历史任务、事件、报告的查询及明细，已查询任务可定位地图 | 固定 Java GET 路径与类型白名单；每轮最多 3 次实际业务查询，分页 20 条、响应有上限；不允许模型修改这些记录 |
| 报告中心 | 从任务/发现创建证据快照，事实初稿、AI 草稿、人工编辑、版本历史、审核冻结、导出 | 快照与 SHA256 固定；版本冲突拒绝；审核时重查证据，发生变化拒绝；审核后不可编辑；模型不能保存/审核 |
| 通勤预约 | 班次、订座/本人退订、延时/取消、生成任务、到达状态 | 1～20 座、未来 30 天范围；行锁防超售；生成任务后冻结订座；复用原通勤任务状态机；起飞窗口为计划前 5 分钟至后 15 分钟 |
| 绕行候选 | 针对禁飞/超高限制区域生成绕行候选，并复用原航线校验 | 保留必经点；限制区域数与候选航点数有上限；仅预览，仍需明确保存；无解时报错，不绕过校验起飞 |

## 数据流和接口

运营表为 `ruoyi/backend/sql/sky_twin_v11_operations.sql`，本轮仅新增表，不清理原业务数据。新环境由 `ruoyi/scripts/migrate-sky.ps1` 依次执行已有迁移和 v11。

`Vue /operations → /sky/operations → Java 业务服务 → 同一 MySQL`。权限沿用 `sky:read / sky:operate / sky:manage`，资源运维和容量修改要求 manage。

- `/tasks`、`/tasks/{id}/retry`：任务列表、关联重试。
- `/resources`、`/resources/{id}/close`、`/stations`、`/stations/{id}/capacity`：运维与容量。
- `/analyses`、`/analyses/{id}/retry`：历史分析与失败重试，明细复用原接口。
- `/flights`、`/flights/{id}`、`/flights/{id}/{delay|activate|cancel}`、`/flights/{id}/bookings`、`/bookings/{id}/cancel`：班次与订座。
- `/reports`、`/reports/{id}`、`/reports/{id}/versions/{revision}`、`/reports/{id}/export?format=txt|html`：报告生命周期。
- `/query`、`/records/{task|event|report}/{id}`：Agent 受限只读业务查询。
- `POST /sky/tasks/{taskId}/route/suggest`：航线候选（位于原航线控制器）。

## 实际边界

- 本项目是仿真运营系统，尚未接真实飞行器、机场或载人设备；订座不代表真实运输、支付或适航能力。
- 充电与维修为人工登记的业务状态，不是设备遥测或自动充电控制。
- 未配置站点容量时默认 200，兼容既有演示数据；容量按整段任务保守占用，不是实机跑道时隙模型。
- 绕行基于平台配置的矩形空域及巡航高度，保守考虑启用区域；不含建筑、地形、气象或实时感知避障，不保证全局最优。
- 报告支持 TXT 和打印版 HTML，HTML 可通过浏览器打印为 PDF；没有服务端直接生成 PDF。AI 草稿需要用户点击并发送该份报告证据给外部模型，失败保留原文本，不自动保存。
- 本地 RAG 现为 4 份白名单文档、25 个片段；检索命中不等于真实模型回答准确率。
